# Bundled fonts

## GohuFont uni14 Nerd Font Mono

- **File:** `GohuFontuni14NerdFontMono-Regular.ttf`
- **GDI face name:** `GohuFont uni14 Nerd Font Mono`
- **Design size:** 14px bitmap (use `FontSizePx: 14` for crisp cells)
- **Source:** [Nerd Fonts](https://www.nerdfonts.com/) patch of [GohuFont](http://font.gohu.org/) (TTF conversion by koemaeda)
- **License:** WTFPL v2 — see `COPYING-LICENSE` (ship freely with software)

Suzuri registers the TTF **privately for the process** (`AddFontMemResourceEx`). End users do not need a system install. Settings can still select any installed monospaced face.

No separate Bold face is shipped; GDI may synthesize bold when requested.
