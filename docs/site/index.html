suzuri（硯） means inkstone — where ink is ground before writing. A native Windows terminal: Win32 + ConPTY + VT cells + Charm chrome. Not a TUI inside someone else’s emulator. Not a Warp fork.

Download for Windows Source on GitHub

Portable .exe · MIT License · amd64

Host, not guest

Owns the window, the PTY, selection, scrollback, and fonts. Shells run for real — PowerShell, cmd, pwsh — not a fake pipe.

Charm chrome

Tabs, command palette, settings, themes, and help are Bubble Tea + Lip Gloss — composited over a dimmed shell, Crush-inspired without the AI product.

Warp-style bar

Local line edit, multiline, history, echo suppression. Full-screen apps reclaim the bottom. Quiet prompts keep the shell clean.

Polish that sticks

Window placement, high-contrast themes, matrix/ripple intros, MCP diagnostics for agents, and GitHub Releases auto-update.
