suzuri（硯） means inkstone — where ink is ground before writing. A native terminal host for Windows and macOS (Apple Silicon): your window, ConPTY / POSIX PTY, VT cells, Charm chrome, Warp-style input. Not a TUI inside someone else’s emulator. Not a Warp fork.

Linux not yet supported as a host build.

Windows

Windows builds are not code-signed yet. SmartScreen may say “Windows protected your PC” — choose More info → Run anyway (or install the setup from GitHub Releases).

Host, not guest

Owns the window, the PTY, selection, scrollback, and fonts. Shells run for real — PowerShell, cmd, zsh, bash — not a fake pipe.

Charm chrome

Tabs, command palette, settings, themes, and help are Bubble Tea + Lip Gloss — composited over a dimmed shell, Crush-inspired without the AI product.

Warp-style bar

Local line edit, multiline, history, echo suppression. Full-screen apps reclaim the bottom. Quiet prompts keep the shell clean.

Polish that sticks

Window placement, high-contrast themes, matrix/ripple intros, MCP diagnostics for agents, and GitHub Releases auto-update.

Session dossier
